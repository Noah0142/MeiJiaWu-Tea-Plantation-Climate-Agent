# 介绍片 · 功能与模型(2:23,带中文旁白)

用 [onetake](https://github.com/feitangyuan/onetake)(PolyForm Noncommercial 1.0.0,非商业使用)做的
**功能与模型介绍片**: 一台相机沿一条竖直的"世界"连续下潜,真实界面、真实数据与画出来的模型图解依次穿过画面;
旁白与逐句字幕由真实时长驱动,底部导轨贯穿全片。

```bash
cd docs/promo/film2
export PATH="/c/Hackthon/AI4Climate/.tools:$PATH"          # ffmpeg / ffprobe(.tools/ 已 gitignore)
ONETAKE="${ONETAKE_DIR:-$TEMP/onetake}"

python capture2.py        # 抓深色版真实界面(大盘 / 对话 / 地图选点实测), 需后端在 127.0.0.1:8000
python crop2.py           # 裁出各章画面块(assets/plates/)
python narrate.py         # 旁白逐句合成(Windows SAPI · Microsoft Huihui zh-CN)+ 真实时长 → assets/narration.js
python make_cjk_css.py    # 中文字体子集(Noto Serif/Sans SC, OFL)
python "$ONETAKE/scripts/look.py" apply look2.json comp2.html     # look.js(产品深色令牌 + 拉丁字面)
python score2.py          # 环境床 + 事件 → bed.wav
python final_mix.py       # 旁白叠上(闪避)→ sfx2.wav
python "$ONETAKE/scripts/probe.py" comp2.html > probe2.txt
python "$ONETAKE/scripts/probe.py" comp2.html
python "$ONETAKE/scripts/render.py" comp2.html --out draft2.mp4 --sfx sfx2.wav
python "$ONETAKE/scripts/verify_promo.py" draft2.mp4 --comp comp2.html --shots 0,15,36,49,66,103,152,174,181
```

## 一、概念:三个,选一个(SKILL §2 硬规则; 与 17 秒短片刻意不同)

1. **一次连续的下潜**(选定)——"世界"是一条竖直的长卷: 地形图、实时大盘、对话、地图选点、模型图解、
   传感器与手机、落版,自上而下排开;一台相机用键控的镜头(落点——停——推近——再落点)一路走下去。
   一直看得见的是底部导轨(章节刻度 + 进度)与左上角的片名章;每个边界都被它们和设备本身承接(卡片不是替换,
   而是被相机推走/拉走)。**排除掉的**: 分屏、贴纸式标注、"功能清单"式罗列。
2. **数据的一生** —— 从 ERA5 的一个格点开始,把数据画成一条河流: 冲刷出特征、汇入模型、分成三条(训练/验证/测试),
   最后滴到一片叶子上。**排除掉的**: 河流隐喻需要大量抽象美术,且与"真实界面"这条原则相冲突(片中会出现真实截图)。
3. **两位农户的一天** —— 从清晨看手机开始,一天里三次用到智能体(看大盘、问一句、地图选点),
   片子就是这条时间线上的三段。**排除掉的**: 需要真实农户出镜或演员,我们没有素材;摆拍会违反"素材真实"的原则。

选定 **1 · 一次连续的下潜**,理由: 介绍片要讲七件事,只有"一条连续的路"能让七件事读成一个产品而不是七页 PPT;
相机是那个"手",它每次停在哪里、推多近,都由旁白讲到的那件事决定。

**视觉: 产品自己的深色令牌**(`--ground #060e09 / --accent #51af6f / --ink #ebe8dc`,即网页版"深色"主题的同一套值),
所以全片的界面截图都是**深色模式实拍**;这与 17 秒短片(浅色纸张 + 手绘线)刻意不同——同一个产品,两种被明确选择过的脸。

## 四、自检

- `probe.py`: 承接/曲线,见 `probe2.txt`(边界是相机推走卡片,不是元素替换)。
- `verify_promo.py`: 见 `verify2.txt`(`cadence` / `rest` / `burst` / `audio` / `continuity` / `curves`)。

## 五、已知限制(如实记录)

- **旁白是 Windows 内置中文 TTS**,清楚但机械(离线可用、无授权问题);要换成真人配音或更好的 TTS,
  只需替换 `assets/narr/*.wav` 后重跑 `final_mix.py`,时间轴不用动。
- **手机三屏是小程序的高保真原型**(浏览器渲染),不是真机截图——`miniapp/` 的代码在开发者工具里跑通后再换成真机截图即可。
- 只出 **1080p30**;4K60(`--final`)等认可后再跑(4291 帧的 4K60 渲染时间约为初稿的 4 倍)。
- 大盘/对话截图里的时间戳是抓取时刻(2026-10-15 19:00),不是拍摄日。
