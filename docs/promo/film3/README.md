# 功能分镜 · 一条线贯穿全片(1:40,浅色,无配音)

第三部: **沿用第一部(17 秒概念片)的浅色纸张与"一条线"语言**(用户指定,不是默认复用),
把主要功能做成七段分镜,**每段单独渲染**(12–18 秒),最后用 ffmpeg 拼接成一个文件。

```bash
cd docs/promo/film3
export PATH="/c/Hackthon/AI4Climate/.tools:$PATH"
ONETAKE="${ONETAKE_DIR:-$TEMP/onetake}"

python capture3.py                       # 浅色素材: 大盘整页 / 地图选点页 / 小程序三屏(需后端在 127.0.0.1:8000)
# 裁块: 见 capture3.py 后的裁切(plates/)
python make_cjk_css.py                   # 中文字体子集(OFL)
python "$ONETAKE/scripts/look.py" apply ../film/look.json comp3.html      # 与第一部同一个 look
python score3.py                         # sfx3.wav(100 秒, 与画面同拍)
bash build3.sh                           # 逐段渲染(comp3.html?seg=N)→ concat → 混音 → film3.mp4
python "$ONETAKE/scripts/verify_promo.py" film3.mp4 --comp comp3.html --shots 0,4,8.6,12,17,23,27,30.5,39,47,56,61,66.8,74,78,89.4,92,100
```

单段渲染/单帧预览: `comp3.html?seg=3`(第 4 段)、`comp3.html?t=41.5&hud`(定位一帧)、`comp3.html?play`(实时播放)。
