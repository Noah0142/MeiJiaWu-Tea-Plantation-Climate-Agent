# 宣传片 · 梅家坞茶园微气候智能体(17.4 s)

用 [onetake](https://github.com/feitangyuan/onetake)(PolyForm Noncommercial 1.0.0, 非商业使用)做的产品宣传片。
一条 HTML 合成(`comp.html`,`window.__seek(t)` 全是时间的纯函数)+ 真实数据 + 实拍界面,1080p30 渲染,
每帧按 `__motion` 自适应的真实快门运动模糊。

```bash
# 可复现(Windows): ffmpeg/ffprobe 见仓库 .tools/(已 gitignore), onetake 脚本在 $ONETAKE(默认下面路径)
cd docs/promo/film
export PATH="/c/Hackthon/AI4Climate/.tools:$PATH"
ONETAKE="${ONETAKE_DIR:-$TEMP/onetake}"          # git clone https://github.com/feitangyuan/onetake

```

## 一、概念:三个,选一个(SKILL §2 硬规则)

概念是**关于画面的一句话**,不是关于产品的一句话。三个各差在"那个想法"上:

1. **一滴水汽的旅程** —— 一个雨滴大小的点从天空落到茶垄上,沿山坡(等温线/坡向)滑下,在谷底结霜,
   变成你手机上的一条预警。元素:一个点;相机:跟随这个点下降。**排除掉的理由**: 需要可信的"茶垄/叶片"美术,
   而我们的素材是数据和界面,不是摄影;一个抽象的点滑过一张图,画面上没有真东西可看。
2. **一条线**(选定)—— 全片只有一条线: 开头它是山脊剖面(DEM 真实横断面),中段它抬起来变成 72 小时气温曲线,
   再长成一个 P10–P90 区间,被 2℃ 受冻临界线横切,然后走进真实的浏览器页面里(同一张图),最后落到落版文字下面当下划线。
   一直看得见的是"这条线本身"和"画它的笔尖"。**它排除掉的**: 卡片式罗列功能(不许出现"功能清单")、旁白、贴纸。
3. **一秒钟的尺度推拉** —— 一台连续运动的相机: 从 1950–2026 年的 ERA5 时间轴拉近到某一小时的某一垄,
   再拉回到农户手里的屏幕。**排除掉的理由**: 15 秒内要表达 76 年 → 1 小时的尺度变化,靠的是字幕解释,
   而"尺度"本身在这段素材里没有可量的参照物(我们没有 76 年的图像,只有一行行的表)。

选定 **2 · 一条线**,理由: 山脊(地形)与气温(预报)在几何上是同一种东西,这条线天生能把"地形 × 气候"这件事
一次讲完;而且它就是我们产品的形状(曲线),不需要任何解说。

## 二、分镜(t · 节拍 · 什么在动 · 什么静止 · 什么承接)

| t (s) | 节拍 | 什么在动 | 什么静止 | 承接 |
|---|---|---|---|---|
| 0.00–1.50 | 笔尖落纸,画出山脊剖面。字: 梅家坞 / 一垄茶山 | 笔尖沿剖面走,线在它身后出现;山体渐渐显形 | 纸面(70% 的空白始终不动) | 线 + 笔尖,进入下一拍 |
| 1.50–2.70 | 剖面**抬起来**变成气温曲线(逐点插值),坐标轴落位。字: 未来 72 小时 / 逐小时预报 | 145 个点同时上抬,笔尖跟着到右端 | 纸面、上一句字(顶出) | 同一条线,换了含义;山体沉下去当水印 |
| 2.70–5.50 | 区间从线上长出来(P10–P90 真实分位数),笔尖第二遍扫过。字: 不是一条线 / 是一个区间;标签 P10–P90 · 80% 置信区间 | 区间的高度从 0 长满(0.55 s),再从左到右扫开;4.10 起**全静止 1.4 s** | 4.10–5.50 画面完全静止 | 线 = 区间的中线,笔尖停在末端 |
| 5.50–7.00 | 2℃ 受冻临界虚线射入、落地(抖动)、标签 + 风险胶囊。全静止 0.7 s | 一条 0.2 s 的横线从左射到右(657 px/帧,靠快门拉丝) | 落定后全静止 | 胶囊的矩形就是下一个场景的起点 |
| 7.00–8.60 | 胶囊张开成浏览器窗口(真实页面整页截图,窗口内可滚) | 卡片矩形从 300×52 长到 1600×944,页面内容随之放大 | 页面本身不动 | 手绘线退场,真实页面接手(同一条颜色) |
| 8.60–11.50 | 指针走到「什么时候采摘?」并点击 → 真实回复(智谱 GLM-4-Flash)出现,静止 1.4 s 读字 | 指针 + 点击;回答出现 | 10.05–11.50 全静止 | 镜头从页面顶部开始下滚 |
| 11.50–13.30 | 下滚到真实的「茶园气温预报」卡: 实况 + P50 + P10–P90 区间 | 窗口内容平滑下滚 1030 px | 窗口本身不动 | 窗口收成卡片,让出画面右侧 |
| 13.30–15.20 | 两张卡片并排: 左 = 真实页面(预报图),右 = 真实地形图(DEM 30m 渲染) + 两处茶园的真实数字。字: 同一片山 / 两处茶园;标签 开采期差 7 天 · 春季霜冻小时差 526 小时(6 年累计) | 窗口缩到左卡;地形卡从右进;同一条线**画在真实地形上**;两个红点与标签弹出 | 13.3 之后的数字静止 | 那条线开始往下走 |
| 15.20–17.40 | 落版: 暗场升起,线落到文字下方变下划线,片名逐字落下 + 两行数据来源 | 线下降到下划线位置;11 个字逐字落 | 16.4 之后全静止 | 唯一允许的"硬切"是这里: 卡片由库里 `liftOut` 抬起离场 |

节奏(verify 用 `--shots` 逐段量): 镜头时长 1.5 / 1.2 / 2.8 / 1.5 / 1.6 / 2.9 / 1.8 / 1.9 / 2.2 s,CV ≈ 0.29(≥ 0.25);

## 四、自检数字(onetake 的 oracle)

- `probe.py`: **continuity 1.00**(1 个边界,由那条线承接;14 → 1 的硬切数来自把折场改成库里 `liftOut` 的真实位移);
  曲线: 峰值 657 px/帧、t80 中位数 0.48、67 个动作(全片没有一个手写的缓动)。
- `verify_promo.py`: 见 `verify.txt`(`cadence` CV、`rest` 静止比例与最长静默、`continuity`、`curves`)。

## 五、已知限制(如实记录)

- 只出了 **1080p30 初稿**;4K60(`--final`)等这版被认可后再跑。
- **无音乐**: 片子里只有音效。要配乐请用可商用授权曲目(NCS / Pixabay / YouTube Audio Library / CC),
  并按 onetake 的要求把曲目来源与许可证和 score.py 放在一起。
- 浏览器窗口里的 URL 写的是 `localhost:8000`(演示时后端就跑在本机);若改成线上地址,重跑 `capture.py` 即可。
- 两处茶园的数字是**模型栅格的多年统计值**(不是实测),片中用"6 年累计"标注,不宣称实测。
