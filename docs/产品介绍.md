# 梅家坞茶园微气候智能体 · 产品介绍

> 用途:招商 / 合作 / 路演 / 政府沟通
> 编制时间:2026 年 10 月 12 日

---

## 一句话定位

**给茶园装一个"懂天气的 AI 管家"** —— 0–72 小时微气候预报 + 霜冻高温预警 + 会说话的农事助手,全部基于公开数据,单园可负担。

## 产品是什么

梅家坞茶园微气候智能体是一个面向茶园经营者的微气候服务系统:它用 76 年公开再分析数据训练出的 AI 模型,把粗糙的公共天气预报"翻译"成茶园尺度的精确预报(未来三天逐小时气温与不确定性区间),再用免费大模型把预报变成茶农听得懂的话 —— "明早 6 点最冷约 15℃,没有霜冻,不用盖防霜布"。

系统包含三部分:**微气候预报引擎**(LightGBM 分位数模型)、**风险预警规则**(霜冻/高温/倒春寒,阈值经农学文献核实)、**自然语言问答助手**(免费大模型,回答严格基于模型预报,不编造数据),统一呈现在一个 Web 仪表盘上。

## 解决什么问题

| 茶农的麻烦 | 我们的答案 |
|---|---|
| 手机天气预报是"城里"的,山谷茶园差好几度 | 用模型把公开预报订正到茶园尺度,逐小时输出 |
| 霜冻、热害来了才知道,减产已经发生 | 提前 0–72 小时分级预警,给出覆盖/熏烟/灌溉等具体操作建议 |
| 气象数据看不懂,没人能问 | 直接问 AI 助手:"明天下午适合采茶吗?" |
| 自建气象站太贵(御茶村式方案需要几十套设备) | 公开数据起步,零硬件也能跑,后期少量锚点站即可校准 |
| 高精度本地数据拿不到、不敢用 | 合规路径已设计好(脱敏/授权/课题合作/替代数据源),演示不依赖涉密数据 |

## 核心功能

1. **0–72h 微气候预报**:逐小时气温(含 80% 置信区间)与湿度,任意近期传感器历史即可驱动;
2. **风险预警卡片**:未来 24/48/72 小时霜冻与高温风险分级(无/轻度关注/中度/重度),附中文农事建议;
3. **AI 农事助手**:多轮自然语言对话,引擎自动降级保底,页面显示当前回答引擎;
4. **历史实况曲线**:气温/湿度/土壤温湿度多图联动,最高/最低标注与缩放;
5. **数据接入卡**:像接入大模型一样填入气象 API 密钥(支持 Open-Meteo),用返回数据直接驱动页面卡片与曲线;
6. **即将上线(演示重点)**:**卫星定位 + 地形图** —— 接入地图 API 与 30m SRTM 地形数据,用户可在地图上**自主选点或圈定范围**,系统读取所选区域的背景场、高程、坡度、坡向与土地覆盖,**重新训练模型**,输出更精准的局部气候预测。

## 使用场景

- **采茶决策**:"明天下午采不采?几点最合适?"
- **防霜决策**:春季凌晨前判断是否覆盖防霜布、是否熏烟;
- **防高温**:夏季判断是否需要遮荫、喷灌与铺草保墒;
- **生产管理**:配合保险机构做气象指数定损;配合农业部门做区域霜冻风险地图。

## 差异化亮点

- **真指标**:内部测试集上 24h 最低气温准确率 74.1%(±2℃),对标行业标杆案例(52%→64%);霜冻预警命中率 0.98;
- **真便宜**:全公开数据 + 免费大模型,无需自建站网,边际成本极低;
- **真可信**:严格三段切分防泄漏训练协议,指标可复现,代码已开源;
- **真能聊**:大模型只解释、不瞎编 —— 每次回答都带着模型预报的原始数字;
- **真能落地**:地图选点 + 地形重训,让用户自己定义"我的茶园在哪",而不是被动接受一个坐标。

## 数据与合规

- 训练与演示使用**全部公开数据**(ERA5-Land 再分析、Open-Meteo 免费接口、10m 茶园分布图),无合规风险;
- 茶田级精确数据目前涉密(仅统计部门内网可查、不可拷贝),产品**不依赖该数据即可完整运行**;我们正按"脱敏申请 → 官方授权/共建 → 联合课题 → 现场查看整理非涉密结论 → 替代数据源"五条合规路径推进,获取后仅用于模型校准,数据不出内网、不进公网;
- 用户数据与密钥本地管理,公网服务不落涉密内容。
