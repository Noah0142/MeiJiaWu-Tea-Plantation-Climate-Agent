## 一、项目概述

**项目名称**:梅家坞茶园微气候智能体(MeiJiaWu Tea Plantation Climate Agent)

**项目性质**:AI4Climate 全球青年气候解决方案挑战赛"方向 01 · 梅家坞气候智慧茶园"参赛项目,面向茶园微气候服务的智能体产品原型。

**一句话概述**:基于 76 年公开再分析数据训练的微气候预报模型,叠加免费大语言模型的农事问答能力,为杭州西湖梅家坞茶园提供 0–72 小时逐小时微气候预报、霜冻与高温热害预警和自然语言农事建议。

**当前状态**:核心预报模型、预警规则、Web 演示与开源代码均已完成(代码已开源,见附录);下一步推进政府数据合规对接与 Demo 功能升级(卫星定位 + 30m 地形图)。

## 二、背景与痛点

**背景**:西湖龙井是杭州农业的名片,梅家坞为核心产区,属典型山谷微地形。公开气象预报为 9–25 公里网格,难以刻画数百米尺度内的山谷温差(冷空气堆积、坡向差异),而春季霜冻(倒春寒)与夏季高温热害直接决定茶叶产量与品质。绍兴御茶村茶园以"40+6 套微型站 + AI 误差订正"将 24 小时最低气温预报准确率从 52% 提升至 64%,验证了本技术路线的可行性。

**核心痛点**:
1. **精度不足**:公开预报分辨率粗,无法反映茶园局地温差;
2. **预警滞后**:霜冻、热害多依赖事后发现,缺少事前分级预警;
3. **信息难用**:气象数据需专业解读,茶农难以直接使用;
4. **建设门槛高**:自建微型气象站网(如御茶村模式)投入大,单个茶园无力承担;
5. **高精度本地数据获取难**:茶田级精确数据涉密,开放渠道有限(详见第六节合规说明)。

## 三、目标与定位

**目标**:建成"低成本、可复制、茶农可用"的茶园微气候智能体;短期在梅家坞形成示范,中长期向杭州乃至浙江产茶区推广。

**定位**:处于"通用天气 App"与"重资产自建气象站"之间的中间层 —— 用公开数据 + 轻量模型 + 大模型交互,把微气候服务成本降到单个茶园可负担的水平。

## 四、解决方案

采用"**大背景 + 小订正**"的 AI 微气候服务架构(对标绍兴御茶村案例):

1. **数据层**:ERA5-Land 再分析(训练)+ 公开数值预报/API(运行时)+ 茶园传感器或线上数据(本地校准);
2. **模型层**:LightGBM 分位数回归,输出 0–72 小时逐小时气温与湿度,含 P10/P50/P90 不确定性区间;
3. **预警层**:基于已核实农学阈值的规则引擎(春霜冻日最低温 ≤4℃ 三级分级、高温热害 ≥35℃、浙江倒春寒标准);
4. **交互层**:免费大语言模型(智谱 GLM-4-Flash)以模型预报为事实依据,提供自然语言多轮问答;
5. **呈现层**:Web 仪表盘;Demo 版升级为地图选点/圈定范围 + 30m 地形叠加。

## 五、产品/服务内容

**现有功能**:
- 0–72 小时逐小时微气候预报(气温 P10/P50/P90 + 相对湿度),支持任意近期传感器历史驱动;
- 霜冻/高温热害/倒春寒三级风险预警卡片;
- AI 农事问答助手(自然语言,回答严格基于模型预报数据);
- Web 仪表盘(预报图、历史实况曲线、风险胶囊、对话窗口、明暗主题);
- Open-Meteo 免费 API 接入(自动取数小卡 + 用户密钥接入卡);
- 命令行模型调用接口(`models/predict.py`),可对接第三方系统。

**Demo 升级规划(即将实施)**:
- **卫星定位**:接入地图 API,允许用户在地图上自主选点或圈定范围;
- **地形图**:接入 30 米分辨率地形数据(SRTM),叠加高程/坡度/坡向等微地形因子;
- **模型重训**:将所选点位的背景场、地形与土地覆盖特征纳入训练,实现更精准的局部气候预测。
- 定位说明:高精度数据完全落地难度大,当前阶段重点是**完整展示"选点—地形—重训—局部预测"的技术思路**。

## 六、技术与数据支撑

**6.1 技术方案**
- 模型:LightGBM 分位数回归(气温 P10/P50/P90、湿度),多时效联合训练;
- 训练协议:严格三段切分(训练 1981–2020 / 验证 2021–2024 / 测试 2025–2026),气候态仅用训练段、早停仅挂验证集、测试集只评估一次,防数据污染;
- 特征:时间谐波、实况滞后与滚动、气候距平、多格点/邻站协同、茶园土地覆盖静态特征;
- 部署:支持锚点站迁移微调、m2cgen 导出纯 JS 模型(零 Python 边缘运行)。

**6.2 模型性能(内部测试集 2025-01 ~ 2026-10,模型训练全程未接触该时段)**
| 指标 | 结果 |
|---|---|
| 总体气温 MAE | 1.52℃(持续预报 2.69℃,相对提升约 41%) |
| 24h 最低气温预报准确率(±2℃) | 74.1%(对标御茶村 52%→64%) |
| 霜冻预警 POD / FAR | 0.98 / 0.19 |
| 不确定性区间覆盖率 | P10–P90 约 78% |

**6.3 数据获取与合规说明**

已获得并使用的公开数据:ERA5-Land 再分析(欧盟哥白尼计划,公开许可)、Open-Meteo 免费接口、全国 10m 茶园分布图(figshare 开放数据)、OpenStreetMap/公开地图服务【待补充确认】。

待授权数据:统计部门持有的茶田级精确数据。该数据**目前涉密,仅可在统计部门内网现场查看,不可拷贝**,项目正与相关部门沟通授权。拟采用的合规路径:

1. **申请脱敏/汇总数据**:请统计部门按行政区划或栅格汇总、去标识化后提供,既不涉密又能支撑模型校准;
2. **申请官方数据授权或合作共建**:以正式函件申请数据使用授权,或将本项目纳入部门合作共建范围,数据不出内网;
3. **联合研究/课题形式**:与统计部门(或其下属研究机构)以联合课题名义立项,我方提供模型与方法,数据由对方在合规范围内使用;
4. **现场查看后整理非涉密结论**:在内网现场查看数据,仅记录与带走"与具体农户无关"的统计结论(如区域均值、空间分布特征),用于验证模型方向;
5. **替代数据源兜底**:若短期无法获得,使用 ERA5-Land 降尺度结果、公开自动气象站(NOAA ISD 杭州站)、卫星地表温度(MODIS LST)与自主部署的低成本微型站逐步补齐。

**使用原则**:任何涉密数据一律不进入公开代码仓库与公网服务;仅使用已授权或脱敏数据训练与展示。

## 九、竞争优势

1. **成本低**:全公开数据起步,无需自建站网即可出 72 小时局地预报;
2. **范式成熟**:沿用御茶村验证过的"误差订正"路线,且有可对标指标(52%→64%);
3. **协议严谨**:严格三段切分与防泄漏设计,测试集指标可信、可复现;
4. **可迁移**:锚点站微调 + 土地覆盖/地形特征,具备跨茶园复制能力;
5. **开源可审计**:代码与训练管线已开源(见附录),便于合作方审查与共建。
